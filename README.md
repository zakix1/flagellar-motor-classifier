# Flagellar Motor Classifier

A Tkinter desktop app that classifies a protein structure as rotating or stalled using persistent-homology features and a saved XGBoost model.

## Requirements

- Python 3.14
- Tkinter (included with the standard Windows Python installer)

Install the Python dependencies:

```powershell
py -m pip install -r requirements.txt
```

## Run the app

```powershell
py flagellar_gui.py
```

Choose a `.ent` or `.pdb` structure file. The app extracts C-alpha coordinates, calculates persistence features, predicts the class, and displays a persistence barcode. Structures with fewer than five C-alpha atoms are rejected.

The GUI uses `best_xgboost_model.pkl`, which matches the seven features currently generated by the app. Raw structure datasets, the local virtual environment, generated plots, and archives are intentionally not part of this repository.
